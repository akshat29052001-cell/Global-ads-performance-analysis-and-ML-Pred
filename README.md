Global Ad Performance & Campaign Revenue PredictionOverviewThis project presents an end-to-end data analysis and machine learning pipeline built on a dataset of 100,000 digital advertising campaigns spanning platforms like TikTok Ads, Google Ads, and Meta Ads. The workflow combines data preprocessing, exploratory data analysis (EDA) with visualization insights, and predictive modeling using Scikit-Learn to forecast campaign revenue.1. Data Preprocessing & CleaningData Inspection & Formatting: Loaded the dataset, standardized column names to lowercase, converted the date column to proper datetime format (datetime64[ns]), and verified there were no duplicate entries.Outlier Capping: Identified skewed distributions across continuous numeric columns (revenue, cpa, roas, conversions, ad_spend, clicks) and mitigated extreme values using the Interquartile Range (IQR) capping method to stabilize the data.2. Exploratory Data Analysis & Key InsightsPlatform Ad Spend & ROAS: Analyzed budget allocation across platforms, showing that Google Ads commands the highest total ad spend while return on ad spend (ROAS) remains relatively consistent across Meta, Google, and TikTok. Cross-analysis by country showed a slight performance edge for TikTok in India and Germany.Campaign Type Efficiency: Evaluated campaign types (Search, Video, Display, Shopping) against cost metrics. Video campaigns proved to be slightly more cost-efficient on a Cost Per Acquisition (CPA) basis.Conversion Rate (CVR) & Attention Traps: Calculated campaign conversion rates to isolate low-converting segments where high click volumes fail to generate proportional conversions.Geographic Market Segmentation: Identified top and bottom-performing markets by ROAS and CPA, highlighting countries like India, Germany, and the UK as high-performing regions.Time-Series & Seasonality Trends: Resampled data monthly (2022–2024) and extracted temporal features (month, quarter) to analyze trends. Quarterly evaluations revealed an evergreen pacing model with minimal seasonal variance across quarters.3. Machine Learning Pipeline & Predictive ModelingTarget Variable & Feature Selection: Filtered out missing revenue values and defined predictive features including categorical variables (platform, campaign_type, industry, country), volume/cost metrics (impressions, clicks, ctr, cpc, ad_spend, cpa, conversions), engineered ratios (cvr), and temporal attributes (month, quarter).Categorical Encoding: Applied one-hot encoding using pandas get_dummies(drop_first=True) to transform categorical attributes into machine-readable format.Model Training: Split the dataset (80% train, 20% test) and trained a RandomForestRegressor with n_estimators=100, max_depth=10, and multi-core parallel processing (n_jobs=-1).Evaluation & Performance: Evaluated the regression model using Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and R-squared ($R^2$):MAE: $11,797.19MSE: 275,673,182.33RMSE: $16,603.41Model Accuracy ($R^2$): 48.94%Visualization: Generated an actual vs. predicted revenue scatter plot overlaying a diagonal reference line to assess residual variance.Tech StackLanguage: PythonLibraries: Pandas, NumPy, Scikit-Learn, Seaborn, Matplotlib
